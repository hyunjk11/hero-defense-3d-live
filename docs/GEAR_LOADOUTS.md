# 장비 보호와 전투 편성

- 가방 상세의 `분해 잠금`은 일반/일괄 분해 양쪽에서 서버가 검사한다. 장착, 강화, 재설정, 창고 이동은 막지 않는다. 잠금 해제도 명시적 서버 액션이며, 원래 아이템/압축 형식은 변경하지 않는다.
- 가방의 `편성` 탭에는 2칸이 있다. 현재 영웅과 선택한 파트너 각각의 장비 ID, 현재 활성 특성 선택을 저장한다. 저장된 장비를 복제하거나 성장/재화를 지급하지 않는다.
- 적용은 한 거래에서 장비/활성 특성/주영웅/파트너를 변경한다. 적용 시 기존 활성 특성 칸의 선택을 교체한다. 다른 특성 칸은 보존한다.
- 창고 또는 사라진 장비, 다른 영웅이 사용 중인 장비, 바뀐 전직, 유효하지 않은 특성/레벨은 전체 적용을 거부한다. 자동 해제, 자동 구매, 부분 적용하지 않는다.
- 저장된 장비가 강화·재설정되었다면 같은 ID의 현재 장비를 사용한다. 장비 능력치를 과거 상태로 돌리지 않는다.
- 서버 비교값과 성장 revision이 달라지면 충돌로 중단한다. 영수증 ID 재실행은 과거 결과만 반환하고 최신 상태를 되돌리지 않는다.
- `lockedGear`, `battlePresets`, `battlePartner`는 서버 보호 필드다. 필드를 모르는 구클라이언트의 저장은 기존 필드를 보존한다. 명시적으로 변경한 일반 저장은 거부한다. 구클라이언트의 이전 stamp 저장은 기존 CAS에서 거부한다.
- 세트 비교는 장착 후 주영웅의 장비/활성 세트 합산 수치 변화 및 활성화/해제 임계치를 보여준다. 전설 자동 효과는 단일 점수에 합치지 않고 원래 설명을 유지한다.

검증: `node --test tests/gear-loadouts.test.mjs tests/loadouts-ui.test.mjs`.
UI 테스트는 DOM mock이며 레이아웃이나 운영 네트워크 검증이 아니다. 배포 시 서버를 먼저 배포한다.
