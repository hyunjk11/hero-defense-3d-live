# 9·10장 로컬 구현 및 검증 기록

2026-10-28. 운영 기준 v18(메모리·냥냥 난타 반영), 로컬 콘텐츠 후보. 이 문서는 운영 배포 완료를 뜻하지 않는다.

## 콘텐츠

- 9장 심연: 소환을 끊고 보호막 지원을 제거하는 장. 균열 가위벌레, 균열 직조자, 공허 집게수문장, 공허 등불해파리, 심연 삼각창, 중간 보스 공명 제단지기, 최종 보스 공허의 문지기 네메시스. 보스는 소환→직선→고리를 교대하고 체력 50%에서 방어를 낮추며 간격을 20% 단축한다.
- 10장 성채: 장갑 노출·대공·포격 회피를 함께 요구한다. 잿불 갈퀴룡, 용비늘 근위대, 불씨 깃발룡, 화로등 용거북, 홍염 비룡, 중간 보스 왕좌의 용창대장, 최종 보스 붉은 용 아르카온. 보스는 브레스→불탄→고리를 교대하고 체력 45%에서 간격을 20% 단축한다.
- 14개 적 역할과 별도 소환체 1종에 전용 절차적 모델·실루엣·애니메이션, 예고 범위, 취약 시간, 사망·정리 경로를 연결했다. 단순 체력 배수만으로 두 장을 구성하지 않았다.
- 소환체는 시전자당 최대 12마리, 동시 생존 최대 12마리. 새 균열 파편충만 골드·정산 처치 보상에서 제외한다. 기존 슬라임 분열체의 보상은 유지한다.
- 고정 방향 공격은 시전 시작 때 방향을 확정한다. 직선·부채꼴 밖, 고리 안쪽과 바깥은 피할 수 있다. 보호막은 중첩하지 않으며 만료·피격 소진·사망·장면 종료에서 해제한다.

## 장비

- 9장 '균열 봉인자': 2세트 사거리 +6%, 3세트 스킬 위력 +12%. 소환·지원 차단 역할.
- 10장 '용화 근위대': 2세트 최대 체력 +8%, 3세트 공격력 +8%. 공성 생존·지속 화력 역할.
- 8개 장비 행(영웅 무기 6, 방어구, 장신구) × 5등급 × 2장 = 이름 80개, SVG 16종, 장착 시 3D 장식. 비공개 영웅 행은 기존 데이터 호환을 위한 정의이며 공개 해금/판매를 추가하지 않는다.
- 등급별 기본 능력치·강화 증가·기존 전설 고유 능력 풀은 보존했다. 새 전설 전용 스킬을 별도 추가하지 않았다. 아이템 이름만으로 새로운 전설 능력을 약속하지 않는다.
- 첫 클리어·보스 드롭·상자·도감·세트 효과·장착·저장을 기존 경로에 연결했다.

## 성장 가정과 전투 검사

이전 장을 실제로 전부 플레이해서 만든 계정이 아니다. 기존 보상/제작/강화/연구/XP 비용 함수를 이용한 성장 가정이다. 장비·돈 무제한 주입 검사가 아니지만 사전 상태 fixture이며, 각 독립 스테이지를 열기 위한 앞 스테이지 완료 표시도 가정으로 주어진다.

- 낮은 성장: 9장 Lv.23, 영혼석 HP8/ATK9, 낮은 연구, 획득 XP의 약 50%를 주 영웅에 투자.
- 기준 성장: 9장 Lv.28, 10장 Lv.31, HP9/ATK8, 화살·마법 연구 ATK8/RNG4/SPD6, 대포 6/3/5, 장비 강화 +8~9. 주 영웅 XP 투자 약 75%.
- 높은 성장: 9장 Lv.41, 10장 Lv.45, HP10/ATK10, 반복 플레이 재화 및 전직을 가정. 전직 재료용 별도 활동은 가정이며 실제 던전 완주 기록은 아니다.
- mixed: 마법·화살·대포 혼합, 빙결/폭풍·저격·폭발. spread: 마법 위주 분산. mobile: 마법 1/3, 화살 2/3와 다중발사, 영웅이 코어 근처 지상 적을 추적. 모든 구매·수리·승급·전문화·전투 집중은 정상 비용과 전투 코드를 호출한다.
- 시간은 G.sim으로 가속했다. 정상 실시간 플레이와 구분한다. seed 12345/23456/34567을 기록했지만 전투 RNG와 시각 RNG가 공유되므로 다른 렌더 조건에서 동일 결과를 보장하지 않는다.

## 검증 및 한계

- Node v24.13.0, 네트워크 차단 래퍼로 전체 61개 파일 통과(기존 58 + 신규 3). 서버 backend 포함. 새 테스트는 몬스터 패턴·안전 지형·시전 중단·보호막 수명·소환 상한·장비 모델·XP 서버 정산 및 중복 방지를 검사한다.
- 실제 Three.js 모델 15종의 유한 bounds/애니메이션 검사. 장비 교체 200회, 소유 material 1,800개가 각 한 번 해제됨. 없는 bone의 재료도 해제함.
- 브라우저 격리 반복 자원 검사: 워밍업 3회 후 20회. geometry/texture/program/scene 수를 비교하고 적·시전·예고·보호막 참조가 0으로 돌아오는지 검사. 최종 발동 완료 검사 수치는 작업 아티팩트의 resources-active-final.json에 기록한다(geometry 127, texture 22, program 47, scene 객체 436으로 전후 동일). JS 장기 heap 안정성 전체를 증명하는 검사는 아니다.
- 실제 UI 정상 속도 9-1·10-1 첫 웨이브→귀환→새로고침. 각각 코어 30, XP +26/+28 및 처치 영혼석 보존. 전 장 실시간 완주를 뜻하지 않는다.
- 10-6은 가속 완주 후 실제 UI로 결과→마을→상자 8개 개봉→장비 상세/장착→새로고침 보존을 확인했다. 기존 3개 장비는 그대로 남았다.
- 화면 검사 중 새 SVG 아이콘 크기 클래스 누락을 발견·수정했다. 초기 독립 스테이지 fixture 두 개는 이전 해금 표시가 없어 레벨 1로 시작했으며 밸런스 표본에서 제외했다.
- 1~8장의 챕터 데이터·기존 적 정의·장비 세트 정의·영웅/타워 수치와 v18 수정 파일을 보존한다. 최종 해시/범위 검사는 작업 아티팩트에 남긴다.
- 실제 사용자 계정/재화/탭, 운영 DB에 테스트 진행을 쓰지 않았다. 운영 v18 유지. 향후 배포 시 클라이언트 콘텐츠와 server/growth.mjs(10장까지 XP 허용)를 함께 반영해야 하며 별도 승인이 필요하다.
- 총사·격투가는 RAM 모의 계정으로 9-6·10-3·10-6을 추가 검사했다. 모든 전직 조합·모바일 장시간 실전·운영 계정 9→10 연속 완주는 미검증. 표본 수를 평균 승률로 포장하지 않는다.

## 공개 5영웅 추가 검사

총사·격투가는 실제 계정을 만들거나 구매하지 않고 localhost 전용 RAM 모의 계정/소유권/XP fixture를 사용했다. 전투 API와 서버 거래 코드는 실제 후보 코드이며 시간만 가속했다.

- 기준 총사: 9-6 mixed는 7웨이브 실패, mobile로 12 완주. 10-3 mobile은 3웨이브 실패. 10-6 mobile은 22 완주.
- 기준 격투가: 9-6은 mobile/mixed 모두 2웨이브 실패. 10-3 mobile 12, 10-6 mobile 두 seed 22/24 완주.
- 높은 성장 총사(Lv.41, 전직 없음): 9-6 mobile 30 완주. Lv.45는 10-3 mobile 12 완주.
- 높은 성장 격투가(Lv.41, 맹호 전직): 9-6 mobile 24 완주.

따라서 유료 영웅이라고 기준 성장의 모든 배치를 자동으로 통과하지는 않았다. 특히 격투가의 9-6 초반 실패는 남아 있는 전술/성장 민감 구간으로 보고한다. 이를 없애려고 기존 영웅이나 챕터 전체를 하향하지 않았다. 고성장/전직 비교는 두 요소가 동시에 달라지므로 어느 하나의 단독 효과로 해석하지 않는다.

10-6 클리어 후 별 1개가 보존되고, 원정 지도에서 재도전 보상(358 영혼석)이 표시됨을 확인했다. 최종장 다음 스테이지는 null이며 11장을 자동 생성하지 않는다. 추가 10-6 격투가 완주 결과 UI에서도 다음 스테이지 버튼이 없고, 모의 서버 영수증은 16웨이브·승리·종료·XP895를 한 번 기록했다(오류 응답 0). 기존 재도전/마을 귀환 동선을 유지하고 별도 엔딩 컷신은 추가하지 않았다.

다음 운영 배포에는 본 콘텐츠 변경만 포함하고 하드·스킬 트리는 섞지 않는다. **설치본 프런트엔드만 운영 v18 API와 조합해 9·10장을 플레이하는 것은 지원 검증 범위가 아니다. v18 API는 8장까지만 XP 출정을 승인하며, 기존 클라이언트 fallback으로 영구 레벨/XP가 없는 전투가 시작될 수 있다. 운영 적용은 새 서버/클라이언트를 반드시 함께 배포해야 한다.** 이번 검증은 일치하는 로컬 서버·클라이언트 또는 로컬 게스트 장부로 수행했다.
