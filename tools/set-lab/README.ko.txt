세트 장비 격리 검증 도구

실행: 저장소 루트에서 Node.js 22로 아래 명령을 실행합니다.
  node --experimental-vm-modules tools/set-lab/run.mjs --out ./set-lab-results

출력 폴더는 새 경로여야 합니다. 기존 증거는 덮어쓰지 않습니다.
results.json: 실행 조건, 실제 수치, 제품 소스 SHA256, 대체 모듈, 한계
report.html: 오프라인으로 열 수 있는 결과표. 네트워크와 스크립트 실행 금지 CSP 적용.
failure.txt: 검사 실패 시 원시 오류. 개인 PC 경로가 포함될 수 있으므로 공개 업로드 금지.

실제 실행하는 운영판 코드
장착/해제, 세이브 정리, 도감/세트 표시, 영웅 생성, 기본 공격,
Q 시전/재사용 제한, 투사체 이동/착탄, 적 체력 차감, 피해 미터.
11개 세트 × 0→1→2→3→2→1→0 상태를 검사합니다.
별도 경계: 사거리 밖/안, 치명타 배율, 피격 체력, 캐릭터별 장착,
공용 장비 이동, 창고 제외, 재장착, 다음 출정 반영, 저장 직렬화/복원.

격리 범위
RAM 시험 계정만 있습니다. 실제 Firebase 계정에 로그인하지 않습니다.
계정 모듈·네트워크·브라우저 저장·동적 import·타이머는 사용할 수 없습니다.
운영 API, 관리자 지급 명령, 인증 토큰, 계정 ID, 서비스 키가 없습니다.
게임이나 서버 진입점은 이 도구를 import하지 않습니다.
Node 전용 도구이므로 GitHub Pages에서 열어 장비를 지급할 수 없습니다.
VM은 불신 코드용 보안 제품이 아닙니다. 검수한 로컬 게임 소스만 실행합니다.

실행 한계
그래픽/WebGL/애니메이션/소리는 대체됩니다. 소리는 출력되지 않습니다.
표적은 특수 능력과 방어가 없는 고정 시험 몬스터입니다.
전투는 기본 마법사로 검증하고, 궁수는 장비 소유권과 파티 스냅샷만 확인합니다.
1/120초 고정 시계와 별도 치명타 샘플을 사용하므로 난이도·성능 측정이 아닙니다.
JSON 복원은 실제 로그인·네트워크 단절·Firestore 저장 검증을 대체하지 않습니다.
실제 브라우저에서 세트 장착 후 전투하는 검사는 별도로 수행해야 합니다.
